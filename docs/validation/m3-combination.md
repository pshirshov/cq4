## Boundary

`Combine` freezes a host-owned plan from a resolved `NotApplied` integration and the current exact claim. The artifact binds owner, governing attempt, repository/target, observed target, original admitted worker/candidate and member revisions. Repeated requests publish the same frozen bytes; a changed request conflicts. Only the matching `Worker(ResolveConflict)` may consume the plan. Same-session claim reacquisition needs a new plan with the current fence; historical worker admission does not authorize new work.

The resolver job prepares the merge under the guardian, reads bounded `MergeReport` pages and returns an ordinary worker report. Capture independently checks workspace identity and immutable ordered parents. Configured checks run on the new candidate; a fresh reviewer receives its handle. A later target advance must reject integration again. Recovery may republish frozen plans and reconcile retained integration evidence; it cannot create a missing plan, renew claims or launch Git.

The deterministic two-governor fixture uses the production supervisor, MCP, PostgreSQL, Git, guardian and validation paths with scripted native consumers. It is separate from the [real model consumer evaluations](m2-consumer-evaluations.md).
